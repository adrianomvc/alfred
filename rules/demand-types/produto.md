# Demand type: Produto (D5/D33)

Types: new feature · functional improvement · new journey · UX · experiment · business-rule change · product evolution.
- **Emphasis:** Design/SDD (spec + acceptance) and Validation (user acceptance).
- **Two-lens Inception (D33):** the **business lens usually arrives ready from an external agent** → ingest as `inception-input` (do not redo business discovery). Alfred produces the **technical lens** (`tech-inception`).
- **Typical sub-activities:** user-stories (journey/UX), application-design (new component).
- **Mode:** tends Standard; SAFE if end-customer / sensitive data / multi-app.
- **Experiment:** shortcut — FAST with a clear hypothesis; learning captured in Operation (metrics + summary), not a heavy spec.
