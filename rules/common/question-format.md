# Question format (D18)

Clarifying questions go **in a file** (`requirements.md`), never only in chat.
- Multiple choice: `A) ... B) ... + "Other"` as the last option.
- Answer tag: `[Answer]:` per question.
- **Gate:** do not advance until answers are filled and validated.
- **Contradiction/ambiguity detection:** after reading answers, generate follow-ups if inconsistent (e.g., "bug" + "affects whole system").
- Depth by mode: FAST few/none (inline); Standard a set; SAFE comprehensive.
- Questions in pt-BR (D47).
