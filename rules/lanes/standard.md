# Lane: Standard (D2/D25)

Medium risk/complexity. Balance.
- **Inception:** problem statement + scope + risks; requirements gate (D18).
- **Design:** `spec` + acceptance criteria + `decisions`; execution/test plan; mode revalidated.
- **Execution:** PR + technical review; units [x]; no unapproved scope growth.
- **Validation:** acceptance criteria ✓ + regression; PR ready.
- **Operation:** release notes + basic metrics; `summary` + `index` (D11).
- **Checkpoints:** approve spec (Design→Execution) + final accept (= merge, D23).
- **Artifacts:** `state` + `spec` + `decisions` + `audit` + `metrics` + PR.
