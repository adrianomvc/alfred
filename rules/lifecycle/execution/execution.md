# Phase: Execution (C.3) — "Do"

Goal: execute aligned to spec, in small traceable changes.

1. Load `spec` + template + active coding-standard (JIT).
2. **Planning:** numbered checklist plan (single source, D19) → approval (Std/SAFE).
3. **Generation:** step-by-step / **per-unit loop** (D24); **brownfield in-place** (never `file_v2`); mirror template (D35) + SOLID (D36).
4. Commit on the **demand branch** each step (D23/D37); update `state`+`audit`; watch **escalation triggers** (D27).
5. Technical review (Reviewer); **Execution DoD** → PR ready.

Outputs: code/changes, PR, evidence, state/audit updated.
