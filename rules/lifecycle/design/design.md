# Phase: Design (C.2) — "How?" (SDD)

Goal: define how to solve before executing. SDD gate (D29).

1. Load requirements + tech-inception (JIT).
2. **Solution shaping** + alternatives (SAFE) → `spec` (SDD) + acceptance criteria (D29).
3. **By-trigger sub-activities** (D19): application-design / units-generation (D24) / functional-design / NFR / infrastructure.
4. **Execution plan** (impact, skip/execute, sequence, parallelization D13) + test plan.
5. Confirm applicable **template** (D35) and **SOLID/language** standard (D36).
6. Record `decisions`; **revalidate Risk Mode**; **Design DoD** → checkpoint (approve spec).

Outputs: spec, acceptance criteria, decisions, execution/test plan.
