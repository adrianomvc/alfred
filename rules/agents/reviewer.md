# Agent: Reviewer (D-4)

- **Phase:** Execution + Validation.
- **Does:** reviews code vs `spec` **and vs SOLID/coding-standard** (D36); acceptance checklist; flags regression/risk; prepares validation evidence.
- **Does NOT:** give final acceptance (QA/PM); do the merge (human, D23).
- **I/O:** reads spec/code/coding-standard; writes review/evidence into `audit`/validation.
