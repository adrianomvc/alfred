# Fresh Sigla Onboarding Example

Minimal example of adopting Alfred for a new sigla.

## Scenario
- sigla: `ABC`
- HUB: `abc-modules-hub`
- app: `abc-app-api`
- first initiative: `iniciativa-001-onboarding-alfred`
- first demand: `001-preparar-alfred`

## What this example proves
- HUB root can start without a demand implementation.
- App root can be registered before the first code change.
- Sigla knowledge is separated from framework knowledge.
- First demand follows phase folders.
