# 002-problem - 006-simulado-adocao-v2

## Problema
A sigla SQ9 opera com artefatos carimbados em versoes 0.x do Alfred. A linha 2.0.0
trouxe guardrails novos (conteudo externo = dado, integridade de testes), template
de skills da sigla, classify-risk e formato de requirements por prioridade — e a
sigla ainda nao registra nada disso.

## Objetivo
Adotar o framework 2.0.0 na sigla: atualizar a referencia, carimbar 2.0.0 nas
demandas novas, criar o registro de skills da sigla a partir do template e validar
o ciclo completo com os validadores.

## Escopo
- referencia de versao do framework na sigla;
- registro de skills da sigla (`004-skills.md` do HUB);
- esta demanda simulada como ensaio ponta a ponta.

## Fora de escopo
- migrar demandas ativas para 2.0.0 (permanecem congeladas — version-adoption);
- adapters reais de host, catalogo externo real.
