# Requirements - 003-simulado-safe

## Requisitos funcionais
- A demanda deve ser classificada como SAFE com justificativa explicita.
- Deve existir `02-design/006-decisions.md` com decisoes de risco, design, validacao e fechamento.
- Deve existir `05-operation/007-audit.md` completo com eventos por fase.
- A spec tecnica deve incluir rollout, rollback e criterios de aceite.
- O `001-state.md` deve permitir retomada sem historico da conversa.

## Requisitos nao funcionais
- Todos os artefatos da demanda devem estar em pt-BR.
- O framework deve continuar markdown-first.
- Nenhum conector externo deve ser obrigatorio.
- SAFE deve gerar mais evidencia que Standard/FAST.
