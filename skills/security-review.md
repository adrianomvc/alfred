# Skill: security-review (example internal skill, D12)

- **Trigger:** security demands / SAFE / sensitive data.
- **Inputs:** changed code/diff, spec, threat-relevant context.
- **Output:** findings (severity, location, recommendation) into validation/audit.
- **Sections (JIT):** authn/authz · input validation · secrets · dependencies.
- **Precedence:** more restrictive wins (D22).
