# Baselines (tunable, D32)

Defaults, NOT hard gates — each squad calibrates (store overrides in the sigla `context.md`). Goal = conversation, not punishment. Human acts (D7).

| Signal | Suggested baseline | Indicates / action |
|---|---|---|
| % SAFE (window ~20) | > ~25% | fear, not risk → review criteria (anti-SAFE, risk-mode) |
| % FAST w/ frequent reclassifications | > ~70% | too light → review checklist |
| Reclassifications / demand | > 1 avg | weak intent analysis (D18/D31) |
| Rework (cycles to accept) | > 2–3 | insufficient clarity (SDD/D29) |
| First-time acceptance | < ~60% | AI output quality dropping → review agents/skills/model-policy |
| Cost/demand vs mode cap | above cap | triggers escalation (D27) |
